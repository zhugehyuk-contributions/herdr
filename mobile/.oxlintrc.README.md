# `.oxlintrc.json` provenance

oxlint rejects unknown top-level keys, so the note that would normally live in a `"//"` field is here.

Ported from orca @ 4fd93ead: the rule set is the union of orca's repo-root .oxlintrc.json and its mobile/.oxlintrc.json overlay, flattened because herdr has no repo-root JS lint config to extend. Dropped: the four `jsPlugins` (config/oxlint-plugins/*.mjs, not part of this port) and every rule they provide, the @linear/sdk no-restricted-imports entry, and the per-file max-lines overrides for orca files that were not ported.
