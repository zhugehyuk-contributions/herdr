 herdr client
   │  ① 화면 채널 unix socket 0600 · 네트워크 리스너 없음
   │     bincode v2 + u32-LE 길이접두 · PROTOCOL_VERSION=14
   │     원격 = ssh fork → herdr remote-client-bridge
   │  ② 제어 채널 newline JSON · 요청 1개당 연결 1개
   │     원격 = ssh fork → herdr remote-api-bridge
   ▼

   공유  AppState 1개 — workspaces·tabs·panes·zoom·mode·view
         effective_size = foreground 클라이언트 크기

         graphics cache·surface_mode·mode(App|TerminalAttach)

서버 수정 (herdr-mx, Rust)

  • S1
    attach 재부착 누수 수정 — M2의 차단 요소

    attach_terminal_client가 client.mode를 덮어쓰면서 이전 terminal의 owner·resize 락을 해제하지 않는다 (headless.rs:2016-2044, 해제는 remove_client :1160뿐). 폰에서 pane 전환하면 이전 pane 크기가 영구 동결. 국소 수정.

  • S2
    InputEvents를 attach pane으로 라우팅

    ClientInput은 apply_terminal_attach_input으로 단락(:2208)하는데 ClientInputEvents엔 그 분기가 없어 앱 입력 경로로 샌다(:2232). 구조화 입력 + 1-pane 조합의 필수 수정.

  • S3
    읽기 전용 attach (락·리사이즈 없음)

    현재 attach는 배타적 — 2번째는 takeover 없으면 거부, takeover는 기존 클라이언트를 ServerShutdown으로 축출(:1991-2013). 폰이 데스크톱과 같은 pane을 보려면 비소유 경로가 필요. 없으면 takeover UX로 대체 가능.

  • S4
    프로토콜 버전 호환 범위 — 출시 전 필수

    check_client_version이 양방향 완전일치(wire.rs:1115, 현재 14). 앱스토어 바이너리는 서버가 15로 올라가는 순간 전부 벽돌. min/max 범위 필요.

  • S5
    foreground 옵트아웃 플래그 — App 표면을 쓸 때만

    폰이 TerminalAttach만 쓰면 불필요(이미 우회). 나중에 herdr 자체 모바일 크롬(ui/mobile.rs)을 폰에서 쓰고 싶어지면 이게 선행 조건 + per-client view/mode 분리(state.rs:1899)라는 깊은 작업이 딸려온다. 초기 범위에서 제외.

모바일 (herdr-mx/mobile, Expo RN)

  • M1
    native ssh 모듈 (iOS/Android) — 두 설계 공통 바닥

    ssh 세션 1개 + exec 채널 N개. 데스크톱은 ControlMaster가 없어 요청마다 ssh 프로세스를 뜨우는데, 모바일이 오히려 더 나은 형태가 된다(채널 다중화).

  • M2
    TS 와이어 코덱

    u32-LE 길이접두 · bincode v2 varint(<251=1B, 251=u16LE, 252=u32LE) · raw deflate(inflateRaw, zlib 아님) · FNV-1a 체크섬 + RequestFullFrame 복구 · packed-u32 색상 / u16 modifier 표. 참조 구현 = tests/server_headless.rs:154.

  • M3
    셀 그리드 렌더러 — xterm.js 불필요

    와이어가 이미 FrameData{cells,width,height,cursor} 셀 그리드다(wire.rs:514). ANSI가 아니라 서버가 렌더한 화면이라 RN 뷰/Skia로 직접 그린다. orca가 xterm webview를 쓴 건 orca 서버가 ANSI를 보내기 때문 — herdr에선 그 단계가 없다.

  • M4
    터치 → ClientInputEvent

    Key/Mouse/Paste 구조화 전송. 터치 픽셀을 자기가 신고한 grid 좌표계의 (column,row)로 변환 — 서버가 그 좌표로 히트테스트한다. 붙여넣기는 MAX_INPUT_PAYLOAD 아래로 청킹(초과 시 드롭이 아니라 연결 종료).

  • M5
    내비게이션 = JSON API

    remote.*/workspace.list/tab.list/pane.list/agent.list + events.subscribe(서버 100ms 폴). 리스트 3계층 + agents 논리 뷰는 전부 여기서 나온다. RN 네이티브 리스트로 그림 — herdr의 TUI 크롬을 쓰지 않는다.
